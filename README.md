# AI Workflow Recommendations

A small React dashboard that explains practical ways to automate team processes with custom GPTs and combine AI tools for research, content creation, and internal linking.

## Content

- Step-by-step process automation guidance
- Recommendations for combining research and language models
- Responsive tabbed interface
- Static GitHub Pages deployment workflow

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
